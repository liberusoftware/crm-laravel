# Liberu CRM Theme

Responsive portal theme for the CRM SaaS application. It owns presentation, semantic tokens, and progressive UI enhancements; module actions, policies, integrations, and billing remain application/module concerns.

The package follows the [Liberu theme architecture](https://github.com/liberusoftware/documentation/blob/main/standards/THEMES.md), declares its assets in `theme.json`, inherits the base theme, targets WCAG 2.2 AA practices, supports dark mode, reduced motion, keyboard focus, zoom/reflow, and small screens.

Install with `composer require liberusoftware/theme-crm`; the host composer installer places it in `/themes/theme-crm`. Build assets with `npm run build`.
