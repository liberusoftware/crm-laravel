# Import and Export Livewire

This optional package is the bounded livewire adapter for liberusoftware/import-export. It presents only the matching core capability; authorization, validation, tenancy, persistence, and business rules remain in the core package.

## Installation

composer require liberusoftware/import-export-livewire

GitHub repository: https://github.com/liberusoftware/module-import-export-livewire.

Compatibility: PHP 8.5+, Laravel 13+, Livewire 4.
