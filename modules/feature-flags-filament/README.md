# Feature Flags Filament

This optional package is the bounded filament adapter for liberusoftware/feature-flags. It presents only the matching core capability; authorization, validation, tenancy, persistence, and business rules remain in the core package.

## Installation

composer require liberusoftware/feature-flags-filament

GitHub repository: https://github.com/liberusoftware/module-feature-flags-filament.

Compatibility: PHP 8.5+, Laravel 13+, Filament 5.
