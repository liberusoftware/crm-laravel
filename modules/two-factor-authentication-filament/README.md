# Two-Factor Authentication Filament

This optional package is the bounded filament adapter for liberusoftware/two-factor-authentication. It presents only the matching core capability; authorization, validation, tenancy, persistence, and business rules remain in the core package.

## Installation

composer require liberusoftware/two-factor-authentication-filament

GitHub repository: https://github.com/liberusoftware/module-two-factor-authentication-filament.

Compatibility: PHP 8.5+, Laravel 13+, Filament 5.
