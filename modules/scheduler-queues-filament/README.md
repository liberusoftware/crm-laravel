# Scheduler and Queues Filament

This optional package is the bounded filament adapter for liberusoftware/scheduler-queues. It presents only the matching core capability; authorization, validation, tenancy, persistence, and business rules remain in the core package.

## Installation

composer require liberusoftware/scheduler-queues-filament

GitHub repository: https://github.com/liberusoftware/module-scheduler-queues-filament.

Compatibility: PHP 8.5+, Laravel 13+, Filament 5.
