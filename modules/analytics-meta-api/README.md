# Meta Server-Side Tracking Api

This optional package is the bounded api adapter for liberusoftware/analytics-meta. It presents only the matching core capability; authorization, validation, tenancy, persistence, and business rules remain in the core package.

## Installation

composer require liberusoftware/analytics-meta-api

GitHub repository: https://github.com/liberusoftware/module-analytics-meta-api.

Compatibility: PHP 8.5+, Laravel 13+, Laravel HTTP API v1.
