# Webhooks Api

This optional package is the bounded api adapter for liberusoftware/webhooks. It presents only the matching core capability; authorization, validation, tenancy, persistence, and business rules remain in the core package.

## Installation

composer require liberusoftware/webhooks-api

GitHub repository: https://github.com/liberusoftware/module-webhooks-api.

Compatibility: PHP 8.5+, Laravel 13+, Laravel HTTP API v1.
