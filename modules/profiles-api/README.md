# Profiles Api

This optional package is the bounded api adapter for liberusoftware/profiles. It presents only the matching core capability; authorization, validation, tenancy, persistence, and business rules remain in the core package.

## Installation

composer require liberusoftware/profiles-api

GitHub repository: https://github.com/liberusoftware/module-profiles-api.

Compatibility: PHP 8.5+, Laravel 13+, Laravel HTTP API v1.
