# Activity and Comments Filament

This optional package is the bounded filament adapter for liberusoftware/activity-comments. It presents only the matching core capability; authorization, validation, tenancy, persistence, and business rules remain in the core package.

## Installation

composer require liberusoftware/activity-comments-filament

GitHub repository: https://github.com/liberusoftware/module-activity-comments-filament.

Compatibility: PHP 8.5+, Laravel 13+, Filament 5.
