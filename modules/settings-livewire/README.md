# Settings Livewire

This optional package is the bounded livewire adapter for liberusoftware/settings. It presents only the matching core capability; authorization, validation, tenancy, persistence, and business rules remain in the core package.

## Installation

composer require liberusoftware/settings-livewire

GitHub repository: https://github.com/liberusoftware/module-settings-livewire.

Compatibility: PHP 8.5+, Laravel 13+, Livewire 4.
