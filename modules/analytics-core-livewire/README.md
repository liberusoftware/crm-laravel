# Analytics Core Livewire

This optional package is the bounded livewire adapter for liberusoftware/analytics-core. It presents only the matching core capability; authorization, validation, tenancy, persistence, and business rules remain in the core package.

## Installation

composer require liberusoftware/analytics-core-livewire

GitHub repository: https://github.com/liberusoftware/module-analytics-core-livewire.

Compatibility: PHP 8.5+, Laravel 13+, Livewire 4.
