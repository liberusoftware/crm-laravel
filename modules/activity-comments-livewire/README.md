# Activity and Comments Livewire

This optional package is the bounded livewire adapter for liberusoftware/activity-comments. It presents only the matching core capability; authorization, validation, tenancy, persistence, and business rules remain in the core package.

## Installation

composer require liberusoftware/activity-comments-livewire

GitHub repository: https://github.com/liberusoftware/module-activity-comments-livewire.

Compatibility: PHP 8.5+, Laravel 13+, Livewire 4.
