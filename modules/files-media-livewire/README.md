# Files and Media Livewire

This optional package is the bounded livewire adapter for liberusoftware/files-media. It presents only the matching core capability; authorization, validation, tenancy, persistence, and business rules remain in the core package.

## Installation

composer require liberusoftware/files-media-livewire

GitHub repository: https://github.com/liberusoftware/module-files-media-livewire.

Compatibility: PHP 8.5+, Laravel 13+, Livewire 4.
