# Currency Context Filament

This optional package is the bounded filament adapter for liberusoftware/currency-context. It presents only the matching core capability; authorization, validation, tenancy, persistence, and business rules remain in the core package.

## Installation

composer require liberusoftware/currency-context-filament

GitHub repository: https://github.com/liberusoftware/module-currency-context-filament.

Compatibility: PHP 8.5+, Laravel 13+, Filament 5.
