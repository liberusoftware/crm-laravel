# Feature Flags Livewire

This optional package is the bounded livewire adapter for liberusoftware/feature-flags. It presents only the matching core capability; authorization, validation, tenancy, persistence, and business rules remain in the core package.

## Installation

composer require liberusoftware/feature-flags-livewire

GitHub repository: https://github.com/liberusoftware/module-feature-flags-livewire.

Compatibility: PHP 8.5+, Laravel 13+, Livewire 4.
