# Jetstream Bridge Filament

This optional package is the bounded filament adapter for liberusoftware/jetstream-bridge. It presents only the matching core capability; authorization, validation, tenancy, persistence, and business rules remain in the core package.

## Installation

composer require liberusoftware/jetstream-bridge-filament

GitHub repository: https://github.com/liberusoftware/module-jetstream-bridge-filament.

Compatibility: PHP 8.5+, Laravel 13+, Filament 5.
