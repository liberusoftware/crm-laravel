# Files and Media Filament

This optional package is the bounded filament adapter for liberusoftware/files-media. It presents only the matching core capability; authorization, validation, tenancy, persistence, and business rules remain in the core package.

## Installation

composer require liberusoftware/files-media-filament

GitHub repository: https://github.com/liberusoftware/module-files-media-filament.

Compatibility: PHP 8.5+, Laravel 13+, Filament 5.
