# Feature Flags Api

This optional package is the bounded api adapter for liberusoftware/feature-flags. It presents only the matching core capability; authorization, validation, tenancy, persistence, and business rules remain in the core package.

## Installation

composer require liberusoftware/feature-flags-api

GitHub repository: https://github.com/liberusoftware/module-feature-flags-api.

Compatibility: PHP 8.5+, Laravel 13+, Laravel HTTP API v1.
