# Module Manager Livewire

This optional package is the bounded livewire adapter for liberusoftware/module-manager. It presents only the matching core capability; authorization, validation, tenancy, persistence, and business rules remain in the core package.

## Installation

composer require liberusoftware/module-manager-livewire

GitHub repository: https://github.com/liberusoftware/module-module-manager-livewire.

Compatibility: PHP 8.5+, Laravel 13+, Livewire 4.
