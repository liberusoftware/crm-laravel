# CRM Activities

Independent team-scoped activity domain for tasks, calls, meetings, emails, deadlines, recurrence, queues, reminders, outcomes, goals, bulk completion, and reporting. Subjects are represented by opaque type/id pairs so the module does not depend on application models.

The existing application task, call, email, reminder, and timeline behavior remains available. This module provides the reusable public boundary and separately owned persistence needed for new composition surfaces.
