# Analytics Core Api

This optional package is the bounded api adapter for liberusoftware/analytics-core. It presents only the matching core capability; authorization, validation, tenancy, persistence, and business rules remain in the core package.

## Installation

composer require liberusoftware/analytics-core-api

GitHub repository: https://github.com/liberusoftware/module-analytics-core-api.

Compatibility: PHP 8.5+, Laravel 13+, Laravel HTTP API v1.
