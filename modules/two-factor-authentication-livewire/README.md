# Two-Factor Authentication Livewire

This optional package is the bounded livewire adapter for liberusoftware/two-factor-authentication. It presents only the matching core capability; authorization, validation, tenancy, persistence, and business rules remain in the core package.

## Installation

composer require liberusoftware/two-factor-authentication-livewire

GitHub repository: https://github.com/liberusoftware/module-two-factor-authentication-livewire.

Compatibility: PHP 8.5+, Laravel 13+, Livewire 4.
