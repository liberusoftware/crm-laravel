# Observability Livewire

This optional package is the bounded livewire adapter for liberusoftware/observability. It presents only the matching core capability; authorization, validation, tenancy, persistence, and business rules remain in the core package.

## Installation

composer require liberusoftware/observability-livewire

GitHub repository: https://github.com/liberusoftware/module-observability-livewire.

Compatibility: PHP 8.5+, Laravel 13+, Livewire 4.
