# Integrations Api

This optional package is the bounded api adapter for liberusoftware/integrations. It presents only the matching core capability; authorization, validation, tenancy, persistence, and business rules remain in the core package.

## Installation

composer require liberusoftware/integrations-api

GitHub repository: https://github.com/liberusoftware/module-integrations-api.

Compatibility: PHP 8.5+, Laravel 13+, Laravel HTTP API v1.
