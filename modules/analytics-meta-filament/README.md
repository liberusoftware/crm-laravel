# Meta Server-Side Tracking Filament

This optional package is the bounded filament adapter for liberusoftware/analytics-meta. It presents only the matching core capability; authorization, validation, tenancy, persistence, and business rules remain in the core package.

## Installation

composer require liberusoftware/analytics-meta-filament

GitHub repository: https://github.com/liberusoftware/module-analytics-meta-filament.

Compatibility: PHP 8.5+, Laravel 13+, Filament 5.
