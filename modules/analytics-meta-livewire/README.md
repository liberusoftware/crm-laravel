# Meta Server-Side Tracking Livewire

This optional package is the bounded livewire adapter for liberusoftware/analytics-meta. It presents only the matching core capability; authorization, validation, tenancy, persistence, and business rules remain in the core package.

## Installation

composer require liberusoftware/analytics-meta-livewire

GitHub repository: https://github.com/liberusoftware/module-analytics-meta-livewire.

Compatibility: PHP 8.5+, Laravel 13+, Livewire 4.
