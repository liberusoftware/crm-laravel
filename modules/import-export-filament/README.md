# Import and Export Filament

This optional package is the bounded filament adapter for liberusoftware/import-export. It presents only the matching core capability; authorization, validation, tenancy, persistence, and business rules remain in the core package.

## Installation

composer require liberusoftware/import-export-filament

GitHub repository: https://github.com/liberusoftware/module-import-export-filament.

Compatibility: PHP 8.5+, Laravel 13+, Filament 5.
