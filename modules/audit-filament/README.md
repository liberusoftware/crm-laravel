# Audit Filament

This optional package is the bounded filament adapter for liberusoftware/audit. It presents only the matching core capability; authorization, validation, tenancy, persistence, and business rules remain in the core package.

## Installation

composer require liberusoftware/audit-filament

GitHub repository: https://github.com/liberusoftware/module-audit-filament.

Compatibility: PHP 8.5+, Laravel 13+, Filament 5.
