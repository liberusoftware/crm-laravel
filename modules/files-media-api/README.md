# Files and Media Api

This optional package is the bounded api adapter for liberusoftware/files-media. It presents only the matching core capability; authorization, validation, tenancy, persistence, and business rules remain in the core package.

## Installation

composer require liberusoftware/files-media-api

GitHub repository: https://github.com/liberusoftware/module-files-media-api.

Compatibility: PHP 8.5+, Laravel 13+, Laravel HTTP API v1.
