# Application Core Filament

This optional package is the bounded filament adapter for liberusoftware/application. It presents only the matching core capability; authorization, validation, tenancy, persistence, and business rules remain in the core package.

## Installation

composer require liberusoftware/application-filament

GitHub repository: https://github.com/liberusoftware/module-application-filament.

Compatibility: PHP 8.5+, Laravel 13+, Filament 5.
