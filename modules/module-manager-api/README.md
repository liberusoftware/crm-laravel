# Module Manager Api

This optional package is the bounded api adapter for liberusoftware/module-manager. It presents only the matching core capability; authorization, validation, tenancy, persistence, and business rules remain in the core package.

## Installation

composer require liberusoftware/module-manager-api

GitHub repository: https://github.com/liberusoftware/module-module-manager-api.

Compatibility: PHP 8.5+, Laravel 13+, Laravel HTTP API v1.
