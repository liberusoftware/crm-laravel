# Organizations and Teams Api

This optional package is the bounded api adapter for liberusoftware/organizations-teams. It presents only the matching core capability; authorization, validation, tenancy, persistence, and business rules remain in the core package.

## Installation

composer require liberusoftware/organizations-teams-api

GitHub repository: https://github.com/liberusoftware/module-organizations-teams-api.

Compatibility: PHP 8.5+, Laravel 13+, Laravel HTTP API v1.
