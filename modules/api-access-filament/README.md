# API Access Filament

This optional package is the bounded filament adapter for liberusoftware/api-access. It presents only the matching core capability; authorization, validation, tenancy, persistence, and business rules remain in the core package.

## Installation

composer require liberusoftware/api-access-filament

GitHub repository: https://github.com/liberusoftware/module-api-access-filament.

Compatibility: PHP 8.5+, Laravel 13+, Filament 5.
