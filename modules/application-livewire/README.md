# Application Core Livewire

This optional package is the bounded livewire adapter for liberusoftware/application. It presents only the matching core capability; authorization, validation, tenancy, persistence, and business rules remain in the core package.

## Installation

composer require liberusoftware/application-livewire

GitHub repository: https://github.com/liberusoftware/module-application-livewire.

Compatibility: PHP 8.5+, Laravel 13+, Livewire 4.
