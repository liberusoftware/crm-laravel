# Organizations and Teams Livewire

This optional package is the bounded livewire adapter for liberusoftware/organizations-teams. It presents only the matching core capability; authorization, validation, tenancy, persistence, and business rules remain in the core package.

## Installation

composer require liberusoftware/organizations-teams-livewire

GitHub repository: https://github.com/liberusoftware/module-organizations-teams-livewire.

Compatibility: PHP 8.5+, Laravel 13+, Livewire 4.
