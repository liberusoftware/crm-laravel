# Sessions and Devices Livewire

This optional package is the bounded livewire adapter for liberusoftware/sessions-devices. It presents only the matching core capability; authorization, validation, tenancy, persistence, and business rules remain in the core package.

## Installation

composer require liberusoftware/sessions-devices-livewire

GitHub repository: https://github.com/liberusoftware/module-sessions-devices-livewire.

Compatibility: PHP 8.5+, Laravel 13+, Livewire 4.
