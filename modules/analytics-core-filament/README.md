# Analytics Core Filament

This optional package is the bounded filament adapter for liberusoftware/analytics-core. It presents only the matching core capability; authorization, validation, tenancy, persistence, and business rules remain in the core package.

## Installation

composer require liberusoftware/analytics-core-filament

GitHub repository: https://github.com/liberusoftware/module-analytics-core-filament.

Compatibility: PHP 8.5+, Laravel 13+, Filament 5.
