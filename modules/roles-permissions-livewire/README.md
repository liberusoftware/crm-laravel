# Roles and Permissions Livewire

This optional package is the bounded livewire adapter for liberusoftware/roles-permissions. It presents only the matching core capability; authorization, validation, tenancy, persistence, and business rules remain in the core package.

## Installation

composer require liberusoftware/roles-permissions-livewire

GitHub repository: https://github.com/liberusoftware/module-roles-permissions-livewire.

Compatibility: PHP 8.5+, Laravel 13+, Livewire 4.
